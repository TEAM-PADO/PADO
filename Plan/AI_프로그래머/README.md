# AI 프로그래머 작업 안내

먼저 [담당 기획서](04_AI_프로그래머.md)를 읽는다. 1단계는 약한 좀비의 감지·공격·사망·재생성과 차량 충돌 반응을 구현하는 것이다. 후속 산출물은 **일반 좀비·보스·수취인 행동 명세**다.

공통 적 상태·플레이어/차량 타깃·스폰 활성/비활성·성능 디버그를 구현하며 의사결정과 적 피해·사망 처리는 서버에서 실행한다. 배달 단계의 보스는 미수락 보호, 실패 시 전투 해제·체력 최대 회복을 적용하고, 처치 이벤트만 코어에 전달해 배송 단계·처치 인정·보상 판정을 받는다. 돈·인벤토리·개인 저장 스냅샷은 플레이어 담당자의 `PlayerState` 소관이다.

1~4인에 따라 일반 좀비의 수·체력만 변경한다. 안전 구역 진입·생성 및 플레이어 주변 스폰을 막고, 첫 결말 전 재생성은 야외 일반 좀비에만 적용한다. 결말 뒤 보스 자유 전투 재등장은 기존 예외다. 로봇의 등장·응답·퇴장과 최종 인간의 반응 이벤트를 제공하며 최종 시네마틱/퀘스트 진행은 코어·UI와 연결한다.
