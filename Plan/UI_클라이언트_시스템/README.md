# UI/클라이언트 시스템 작업 안내

먼저 [담당 기획서](06_UI_클라이언트_시스템.md)를 읽는다. 1단계는 첫 차 구매, 후보 지도·타이머·목표, 택배 표시와 배송, 완료·보상 표시다. 후속 산출물은 **화면 흐름도·와이어프레임·상태 표시표**다.

공용 입력: [기본 규칙](../공용/00_기획핵심과_미결정.md) · [단계별 범위](../공용/01_개발순서.md) · [배달·저장 상태](../공용/07_배달_상태와_저장_규칙.md) · [목적지 ID](../공용/09_배달_콘텐츠_진행표.md) · [화면 흐름·문구](../공용/11_화면_흐름_요구사항.md) · [수취인·결말 연출](../공용/12_수취인_이야기_연출안.md) · [와이어프레임 작성 요청](../공용/13_팀원별_문서_작성_요청.md).
