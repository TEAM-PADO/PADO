# UI/클라이언트 시스템 작업 안내

먼저 [담당 기획서](06_UI_클라이언트_시스템.md)를 읽는다. 1단계는 메인 메뉴의 새 게임·이어하기·삭제, 공개/친구(초대 전용) 방 설정과 공개 목록·스팀 초대 즉시 입장, 첫 차 구매, 후보 지도·타이머·목표, 택배 표시와 배송, 완료·보상 표시다. 후속 산출물은 **화면 흐름도·와이어프레임·상태 표시표**다.

체력·탄약·장착 총 HUD, 메뉴 입력·상호작용 안내, 월드 위치의 지도 좌표 변환·핀 표시는 UI가 맡는다. 월드 대상 탐색·캐릭터 입력·일반 인벤토리와 택배 전용 슬롯 기능은 전투에서, 코어 발급 배송지 ID·공유 확정 상태는 코어에서, 실제 위치·제작용 명칭·ID가 할당된 Anchor는 레벨에서 받는다. 개인 돈·인벤토리·장비는 플레이어 담당자의 복제 `PlayerState`를 표시한다. 표시명과 콘티는 기획자가 승인한다. **컷신 제작 계획·자산 취합·통합·재생과 공동 제작 자산 목록 취합은 UI/클라이언트가 주관**하고, 실제 자산 제작 담당은 목록에 항목별로 지정한다.

입력은 `PlayerController` 등의 서버 요청으로 연결하고, 코어가 배달·방 규칙을 검증해 `PlayerState` 공개 서버 API로 개인 변경을 요청한 뒤 복제된 `GameState`·`PlayerState`를 표시한다. UI는 보상·타이머·자격을 독자 판정하지 않으며 거리·돈·상태·택배 부족 등 거절 이유는 서버 응답을 사용한다. 택배 전달은 땅에 드롭한 뒤 동료가 줍는 흐름이다. 총 습득·드롭·사망 아이템 드롭은 전투 파트의 서버 결과를 표시한다.

남은 시간 표시는 동기화된 서버 시간·마감 시각을 기준으로 보간할 수 있지만, 감액·만료·완료/실패의 판정은 서버 결과를 따른다.

화면 전환·모달·입력 모드, 로딩·접속·재접속·호스트 종료, 공통 알림과 지연·중복 클릭 처리를 담당한다. 합류자의 현재 목표·보상 자격과 마지막 배송자의 선택 권한을 명확히 표시하고, 키보드/마우스·게임패드·해상도·화면 안전 영역·색각 보조·자막·UI 스케일을 검수한다. 개인 저장 형식·스냅샷은 플레이어 담당이며 방 저장 호출·취합은 코어 담당이다.
