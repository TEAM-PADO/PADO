# UI/클라이언트 시스템 — 배달, 상점과 결말 화면

기준: [기본 기획](../공용/00_기획핵심과_미결정.md) · [개발 순서](../공용/01_개발순서.md)

## 맡는 결과

팀원이 지금 갈 곳, 남은 시간, 배송 가능 여부, 보상과 저장 상태를 알아보고 필요한 행동을 할 수 있게 만든다. 배달·구매·마지막 선택은 클라이언트에서 입력받되, 확정 결과는 호스트 상태를 따른다.

UI는 화면·메뉴 입력·상호작용 안내를 구현한다. 월드 상호작용 대상 탐색·우선순위·캐릭터 입력과 일반 인벤토리·택배 전용 슬롯·장착·아이템 이동 기능은 플레이어 전투가 구현하며, UI는 해당 상태를 표시하고 메뉴의 조작 요청을 연결한다. 체력·탄약·장착 총 HUD도 UI가 제작하고 전투 파트가 상태를 제공한다.

공통 요청 흐름은 `UI/플레이어 입력 → PlayerController 등의 Server RPC → 코어의 배달·방 규칙 검증 → PlayerState 공개 서버 API로 개인 보상/인벤토리 변경 요청 → 복제된 GameState·PlayerState 표시`다. 총 습득·드롭과 사망 아이템 드롭은 플레이어 전투의 서버 처리 결과를 따른다. `GameState`의 공유 진행·목적지 ID·타이머·보스·결말 상태는 코어가 제공하고, `PlayerState`의 돈·인벤토리·개인 장비 상태는 플레이어 담당자가 제공한다. UI는 결과·보상·타이머·자격을 독자 판정하거나 개인 상태를 직접 변경하지 않는다.

## 공통 클라이언트 기반

- 화면 전환·모달·팝업 우선순위·입력 모드를 관리하고 공통 알림·토스트·확인창을 제공한다. 화면 구성은 UMG, 메뉴·입력 레이어·게임패드 대응은 Common UI, 입력 문맥 전환은 Enhanced Input을 검토한다.
- 로딩·접속·재접속·호스트 종료와 네트워크 상태·서버 응답 실패를 안내한다. 중복 클릭·접속 지연·서버 응답 지연을 처리하고 요청 대기·승인·거절 상태를 구분한다.
- 수락·배송·문 열기·수취인 확인 예외·택배 드롭/줍기·총 줍기·구매·수리·승하차 요청을 해당 서버 API에 연결한다. 거리 부족·돈 부족·상태 불일치·택배 없음 등 최종 거절 이유는 서버 응답으로 표시하며 로컬 추측으로 대체하지 않는다.

## 메인 메뉴와 방 입장

- 메인 메뉴의 항목은 **게임 시작 / 게임 참가 / 게임 종료**다. 별도 로비 레벨은 없다.
- **게임 시작**은 첫 구현에서 호스트별 **저장 게임 1개**만 보여준다. 저장이 없으면 **새 게임**, 저장이 있으면 **이어하기·삭제**를 제공한다. 기존 저장이 있을 때 새 게임은 삭제 확인 후 진행하며 자동으로 덮어쓰지 않는다. 단일 슬롯의 저장·재개·삭제 검증 후 여러 저장 게임의 목록·선택으로 확장한다. 이어하기 또는 새 게임으로 방을 열 때 **공개 / 친구(초대 전용)**를 선택하며, 확정 후 곧바로 게임 지도에 들어간다.
- **게임 참가**에서는 공개 방 목록을 보여주고 선택한 방에 참가한다. 친구(초대 전용) 방은 공개 목록에 나타나지 않으며, 받은 **스팀 초대**로 참가한다. 어느 경로든 참가가 승인되면 로비 화면을 거치지 않고 진행 중인 게임에 바로 들어간다. 정원 초과 또는 참가 실패는 메뉴에서 이유를 알 수 있게 표시한다.

## 화면과 상호작용 규칙

- 저장 슬롯 수는 저장 가능한 게임 수다. 최종 문 앞 체크포인트는 같은 게임의 별도 저장 상태이므로, 단일 슬롯에서도 일반 저장과 체크포인트를 구분해 불러올 수 있게 한다. 여러 슬롯으로 확장한 뒤에는 선택한 게임의 저장 상태만 표시한다.

- 배달 후보 지도는 **우체국에서만** 열 수 있다. 최종 규칙에서는 최소 9곳 이상인 일반 배송지 풀에서 서버가 무작위로 고른 **일반 후보 3개**를 보여준다. 완료 후에는 남은 2개를 유지하고 새로 뽑은 후보 1개를 표시하며, 실패·중단한 건은 재수락 가능 상태로 유지한다. 미완료 보스 배달이 해금되면 일반 3개와 별도 고정 보스 1개로 **총 4개**를 보여준다. 1단계의 후보 1개 화면은 임시 통합 범위다. 진행 중 다른 건도 수락할 수 있으며 기존 건 중단·택배 제거·보상 없음·새 시간 시작을 미리 알린다. 팀은 교체 후에도 한 건의 목표를 공유한다.
- 누구든 수락할 수 있고 수락 순간부터 호스트 타이머가 흐른다. 우체국·상점·도로·배달지 사이를 이동할 때도 표시 타이머는 계속 흐른다. 일반 배달은 보상 감소 시점과 최종 마감, 보스 배달은 처치 제한시간만 구분해 보여준다. 보스 처치 후에는 배송에 시간제한이 없음을 분명히 표시한다.
- 타이머 화면은 동기화된 서버 시간·마감 시각을 기준으로 표시를 보간할 수 있다. 보간된 로컬 표시가 0에 도달해도 감액·만료·실패·보상·배송 가능 상태는 서버의 확정 결과를 따른다.
- 택배는 일반 인벤토리와 구분한 **택배 전용 슬롯**에 표시한다. 동료 전달은 땅에 드롭한 뒤 동료가 줍는 흐름으로 안내하며 별도 직접 전달 기능을 만들지 않는다. 사망 아이템은 개별로 줍고 플레이어별 최근 사망 1회분만 현장 유지하며 다음 사망 때 이전 미회수분의 안내를 제거한다. 직접 내려놓은 일반 아이템의 3분 정리와 택배 예외를 구분하고 제거 결과는 서버 상태를 따른다. 택배 전달·회수·최종 제한시간 만료·완료·중단·교체에 따른 제거를 즉시 반영한다. 실패한 배달은 우체국에서 새 택배로 재수락할 수 있고, 현장 회수는 필수 목표로 표시하지 않는다. 탑승 자체에 별도의 택배 운반 제한은 두지 않는다.
- 사망자는 생존자 복귀 대기와 전멸 자동 부활을 구분해 안내한다. 생존자가 모두 우체국 밖이면 우체국 복귀 안내·방향을 보여주고, 생존자 한 명이 우체국 내부에 도착하면 사망한 팀원 전원이 부활한다. 이미 내부에 생존자가 있으면 조건을 충족한다. 기존 몸→데이터 이탈·우체국 귀환→필요 시 대기→새 몸 진입→조작 복귀 연출을 호스트 상태에 맞춘다. 사망·대기·연출 중에는 체력 0과 계속 흐르는 배달 시간을 표시하고, 조작 복귀 전 공격·줍기 안내를 제공하지 않는다. 구체적인 문구는 [화면 요구사항](../공용/11_화면_흐름_요구사항.md)을 따른다.
- 차와 총 구매, 차량 유료 수리, 소지 코인과 소유 상태를 보여준다. 첫 총 구매 후보는 라이플·샷건·스나이퍼 각 150코인이다. 탄약 구매와 총·차 판매 동작은 제공하지 않는다. 자동 저장은 배달 완료·우체국 도착·보스 배달 3종의 처치 직후 일어나고, 최종 배달의 문 앞 체크포인트는 별도로 저장되므로 각각의 저장 완료 시점을 플레이어가 알 수 있게 표시한다.
- 보상 화면에는 완료 보상과 좀비 처치 보상을 구분한다. 수락 이후 처음 합류한 참가자는 현재 배달에 참여할 수 있지만 완료 보상 대상이 아님을 알 수 있어야 한다. 중간 이탈 뒤 완료 전에 재합류한 자격자는 정상 대상으로 보인다.
- 중도 합류·재접속 화면에서 현재 배달 목표와 개인 보상 자격을 함께 동기화한다. 수락 당시 참가자·완료 당시 접속 여부와 재접속 자격은 코어가 판정한 결과를 표시한다. 전멸했어도 제한시간이 남았다면 서버 상태에 맞는 부활·재도전 안내를 제공한다.
- 총기·탄약·돈·처치 보상, 총 드롭/줍기 전달, 차량 구매·수리·상태·내구도, 좌석 구성·현재 좌석과 `Ctrl+1~4` 좌석 변경 안내를 제공한다. 운전자 사격 불가·동승자 사격 가능 등 행동 가능 여부는 전투 파트의 서버 상태에 맞춰 표시한다.
- 보스 배달 3종 모두 처치 직후 서버 저장 성공 응답에 따라 자동 저장 완료를 표시하고, 불러오면 해당 배달지 문 앞에서 보스 처치 완료·배송 무제한·택배·보상 자격을 복원해 이어간다고 안내한다. 우체국 도착 저장이 갱신돼도 활성 보스 배송 대기는 문 앞에서 재개한다. 결말 뒤 자유 전투 처치에는 이 저장 표시를 띄우지 않는다.
- 최종 배달에서 보스 처치 후 택배 소지자가 마지막 문 앞에 도착하면, 노크·선택 전에 별도 체크포인트가 저장됐음을 보여준다. 불러오기 화면에서 일반 저장과 문 앞 체크포인트를 구분하고, 문 앞 체크포인트를 고르면 그 뒤의 코인·장비·일반 배달 진도가 되돌아간다는 내용을 선택 전에 보여준다. 체크포인트는 결말 뒤 일반 저장을 계속해도 선택 가능해야 한다.
- 일반 배달은 택배를 소지하고 문 앞에서 상호작용하면 완료되며 수취인 확인 선택은 없다. 첫 보스 처치 후에는 상호작용으로 로봇 수취인이 나와 받는다. 둘째·셋째는 수취인이 나오지 않아 실제 택배 전달자에게 문 열기/확인 없이 완료 선택을 표시한다. 둘째는 충전 중 로봇 확인 시 정상 보상, 확인 생략 시 감소 보상(차감액·비율 미정)을 표시한다.
- 셋째에서 들어가면 인간을 좀비로 만드는 팀 공동 해피엔딩 컷신과 「ai의 시대」 도전과제를 표시한다. 열지 않으면 인간 번영 결말과 「인간을 지켜준 로봇」 도전과제를 표시한다. 문을 연 결말에서만 좀비 한 마리가 집 밖으로 나오고 이후 집은 비어 있다. 배달 규칙·완료·보상·결말·도전과제 판정은 네트워크/코어가 맡고 UI는 확정 결과를 표시한다. 결말 뒤 같은 방의 일반 배달과 완료한 보스 3마리의 자유 전투를 안내하며 자유 전투 보상은 없다.
- 문 열기/수취인 확인 예외의 선택 권한은 코어가 지정한 실제 배송 플레이어에게만 활성화한다. 다른 팀원에게는 선택 대기와 확정 결과를 표시한다. 공유 컷신 진입·스킵 정책·엔딩·업적도 서버가 확정한 공용 상태를 따라 전원에게 같은 결과를 보여준다. 스킵 정책은 기획 확정값을 표시하며 클라이언트가 결말을 따로 진행시키지 않는다.

## 접근성과 화면 품질

- 키보드/마우스와 게임패드의 현재 입력 장치에 맞는 안내를 제공한다.
- 해상도·화면 안전 영역·UI 스케일, 색각 보조·자막을 지원하고 긴 배달명·설명·수취인 대사에서 잘림과 레이아웃 겹침을 확인한다.
- 접속 지연·중복 클릭·서버 응답 지연·거절·재접속을 1/2/4인 호스트·클라이언트 화면에서 확인한다. 화면 전환과 모달이 캐릭터 입력 또는 최종 선택 권한을 가로채지 않게 한다.

## 다른 파트와의 경계

- 네트워크 코어에서 방 목록·참가 승인/거부·저장 데이터 목록/삭제 결과, `GameState`의 후보·타이머·공용 문 선택 상태, 개인 보상 자격·저장 완료 결과를 받는다. 개인 돈·인벤토리·장비는 플레이어 담당자가 구현한 복제 `PlayerState`의 상태를 표시한다. 클라이언트가 자체 계산한 시간·돈·자격으로 배달을 완료 처리하지 않는다. 개인 저장 스냅샷·직렬화는 플레이어 담당이며 방 저장 호출·취합은 코어 소관이다.
- 레벨디자이너는 목적지·상점·현관·우체국의 실제 월드 위치와 제작용 명칭을 제공하고 코어 발급 `DeliveryLocationId`를 Anchor/Actor에 할당한다. 코어는 배달 데이터와 Anchor 매칭을 검증한다. UI가 유효한 ID의 월드 위치를 지도 좌표로 변환하고 핀을 표시하며, ID 생성·변경·배달 결과 판정을 하지 않는다. 플레이어에게 보이는 표시명은 기획자가 승인한다.
- AI가 수취인 등장·응답·문을 열었을 때 확인 대상을 제공한다. 컷신의 콘티는 기획자가 확정하고, UI/클라이언트가 콘티를 바탕으로 카메라·시퀀스·애니메이션·VFX·사운드의 제작 계획과 자산 취합·통합·재생을 주관한다. AI·전투는 필요한 동작을, 레벨은 연출 공간을 제공한다. 실제 자산 제작 담당은 [공동 자산 목록](../공용/13_팀원별_문서_작성_요청.md)에 항목별로 지정한다. 최종 인간 컷신은 호스트의 선택 결과를 받아 팀 전체에 재생한다.
- 플레이어 전투가 좌석·총·탄약·차량·체력·일반 인벤토리·택배 전용 슬롯·장착 상태, 월드에서 선택한 상호작용 대상과 줍기·수리의 기능상 가능 조건을 제공한다. UI는 이 상태로 HUD와 상호작용 안내를 제작하고 메뉴 요청을 연결한다. 총 습득·드롭·사망 아이템 드롭은 플레이어 전투의 서버 처리와 `PlayerState` 변경 결과를 표시한다. 비용·소유권·배달 상태에 따른 요청 허용 여부는 담당 서버 API의 검증 결과를 따르고, 거절 이유는 응답으로 표시한다.
- UI/클라이언트가 제작 자산 목록을 취합하고 항목별 제작 담당·필요 수량·완료 상태를 관리한다. 레벨·AI·전투는 자기 파트와 컷신에 필요한 자산을 제출하며 기획자가 우선순위·콘티·체감 품질을 승인한다. 통합 검증·성능 측정의 총괄은 코어가 맡고 UI는 화면·메뉴·컷신 영역의 실행 결과를 제공한다.

## 완료 확인

새 게임·이어하기에서 공개/친구(초대 전용)를 선택할 수 있고, 공개 방은 목록 참가, 초대 전용 방은 스팀 초대로만 입장하며 두 경로 모두 로비 없이 게임으로 들어간다. 일반 후보 3개와 별도 보스 항목이 동시에 보여도 구분된다. 모든 서버 판정 상태가 HUD·메뉴에 일관되게 반영되며 UI가 보상·타이머·자격을 독자 판정하지 않는다. 1~4인에게 같은 진행 단계와 타이머가 표시되고, 수락 후 최초 합류자와 이탈 후 재접속 자격자가 현재 목표·각자의 보상 자격을 명확히 구분한다. 일반 배달의 보상 감소·실패, 보스 처치 후 시간 무제한 배송, 우체국 도착 저장, 택배 전용 슬롯·드롭/줍기 전달·서버 거절 이유를 실제 플레이에서 확인한다. 마지막 선택은 배송한 플레이어에게만 활성화되고 결과·팀 공동 컷신·엔딩은 전원에게 동일하게 표시된다.
