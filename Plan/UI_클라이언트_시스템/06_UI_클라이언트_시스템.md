# UI/클라이언트 시스템 — 배달, 상점과 결말 화면

기준: [기본 기획](../공용/00_기획핵심과_미결정.md) · [개발 순서](../공용/01_개발순서.md)

## 맡는 결과

팀원이 지금 갈 곳, 남은 시간, 배송 가능 여부, 보상과 저장 상태를 알아보고 필요한 행동을 할 수 있게 만든다. 배달·구매·마지막 선택은 클라이언트에서 입력받되, 확정 결과는 호스트 상태를 따른다.

## 메인 메뉴와 방 입장

- 메인 메뉴의 항목은 **게임 시작 / 게임 참가 / 게임 종료**다. 별도 로비 레벨은 없다.
- **게임 시작**에서는 저장된 게임 진행 데이터를 목록으로 보여주고 각 데이터의 **이어하기·삭제**와 **새 게임** 진입을 제공한다. 이어하기 또는 새 게임으로 방을 열 때 **공개 / 친구(초대 전용)**를 선택하며, 확정 후 곧바로 게임 지도에 들어간다.
- **게임 참가**에서는 공개 방 목록을 보여주고 선택한 방에 참가한다. 친구(초대 전용) 방은 공개 목록에 나타나지 않으며, 받은 **스팀 초대**로 참가한다. 어느 경로든 참가가 승인되면 로비 화면을 거치지 않고 진행 중인 게임에 바로 들어간다. 정원 초과 또는 참가 실패는 메뉴에서 이유를 알 수 있게 표시한다.

## 작업 묶음

| 단계 | 산출물 |
|---|---|
| 1. 배달 한 건 | 메인 메뉴·저장 데이터 선택/삭제·새 게임, 공개/친구(초대 전용) 설정, 공개 방 목록·스팀 초대 입장, 개인 코인·첫 차 구매, 지도에서 일반 배달 후보 1개와 완료 후 다음 후보 표시·수락, 목표·타이머, 인벤토리의 택배 표시와 배송 상호작용, 완료·보상·저장 표시 |
| 2. 반복 플레이 | 일반 후보 최대 3개와 보충 표시, 첫 시간 기준의 보상 감소·최종 실패 안내, 총·차 상점, 인벤토리·아이템 줍기/전달, 동승·내구도·수리, 합류자 목표 표시 |
| 3. 보스·결말 | 일반 후보와 별도 고정 보스 배달, 보스 처치 제한시간과 처치 후 무제한 배송 전환, 최종 문 앞 체크포인트 저장·불러오기와 진행 되돌리기 안내, ‘충전 중’ 응답 뒤 수취인 확인/확인 예외, 팀 공동 컷신·엔딩·업적, 결말 뒤 일반 배달·보스 재등장 안내 |

## 화면과 상호작용 규칙

- 배달 후보 지도는 **우체국에서만** 열 수 있다. 첫 콘텐츠판의 일반 목적지 9곳 중 무작위 **최대 3개**를 보여준다. 완료·실패한 일반 배달 자리는 새 후보로 채우며 완료한 목적지도 즉시 다시 등장할 수 있다. 해금된 보스 배달은 별도 항목으로 완료할 때까지 고정해 보여준다. 팀에서 한 건만 진행 중일 때는 모두 같은 목표를 본다.
- 누구든 수락할 수 있고 수락 순간부터 호스트 타이머가 흐른다. 우체국·상점·도로·배달지 사이를 이동할 때도 표시 타이머는 계속 흐른다. 일반 배달은 보상 감소 시점과 최종 마감, 보스 배달은 처치 제한시간만 구분해 보여준다. 보스 처치 후에는 배송에 시간제한이 없음을 분명히 표시한다.
- 택배는 여유 있게 제공한 일반 인벤토리 슬롯에 표시한다. 택배 전달·사망 시 투하·재획득·배달 종료 시 제거가 화면에 즉시 반영되게 한다. 탑승 자체에 별도의 택배 운반 제한은 두지 않는다.
- 차와 총 구매, 차량 유료 수리, 소지 코인과 소유 상태를 보여준다. 첫 총 구매 후보는 라이플·샷건·스나이퍼 각 150코인이다. 탄약 구매와 총·차 판매 동작은 제공하지 않는다. 일반 저장은 배달 완료와 우체국 도착 때 일어나고, 최종 배달의 문 앞 체크포인트는 별도로 저장되므로 각각의 저장 완료 시점을 플레이어가 알 수 있게 표시한다.
- 보상 화면에는 완료 보상과 좀비 처치 보상을 구분한다. 수락 이후 처음 합류한 참가자는 현재 배달에 참여할 수 있지만 완료 보상 대상이 아님을 알 수 있어야 한다. 중간 이탈 뒤 완료 전에 재합류한 자격자는 정상 대상으로 보인다.
- 최종 배달에서 보스 처치 후 택배 소지자가 마지막 문 앞에 도착하면, 노크·선택 전에 별도 체크포인트가 저장됐음을 보여준다. 불러오기 화면에서 일반 저장과 문 앞 체크포인트를 구분하고, 문 앞 체크포인트를 고르면 그 뒤의 코인·장비·일반 배달 진도가 되돌아간다는 내용을 선택 전에 보여준다. 체크포인트는 결말 뒤 일반 저장을 계속해도 선택 가능해야 한다.
- 현관에서 노크하면 평범한 로봇 수취인은 직접 나와 확인·수령한다. **‘충전 중’ 응답을 받은 경우에만** 문 열기와 수취인 확인 예외 기록 선택을 제공한다. 보스 배달 3곳은 의심 주소로 안내하고 최종 배달은 매우 의심스러운 주소이므로 반드시 확인하라는 시스템 지시를 보여준다. 그래도 마지막 배달의 확인 예외는 선택 가능하다. 마지막 배달에서는 **실제로 택배를 전달한 플레이어**가 문 열기를 결정하며, 팀 전원에게 같은 컷신·결말을 보여준다. 문을 열지 않은 결말에는 「진실을 외면!」 업적을 부여한다. 문을 열어 약을 주입한 결말에서만 좀비 한 마리가 집 밖으로 나오고 이후 집 안은 비어 있다. 결말 뒤에는 같은 방에서 일반 배달을 계속하고 완료한 보스 3마리와 배달 수락 없이 자유 전투할 수 있음을 보여준다. 자유 전투에는 배달 보상이나 별도 처치 코인이 없다.

## 다른 파트와의 경계

- 네트워크 코어에서 방 목록·참가 승인/거부·저장 데이터 목록/삭제 결과와 후보·타이머·보상 자격·저장 완료·문 선택의 확정 상태를 받는다. 클라이언트가 자체 계산한 시간이나 돈으로 배달을 완료 처리하지 않는다.
- 레벨디자이너가 목적지·상점·현관·우체국 위치와 표시용 이름을 제공한다.
- AI가 수취인 등장·응답·문을 열었을 때 확인 대상을 제공한다. 최종 인간 컷신은 호스트의 선택 결과를 받아 팀 전체에 재생한다.
- 플레이어 전투가 좌석·총·차량·체력 상태와 줍기·수리 가능 조건을 제공한다.

## 완료 확인

새 게임·이어하기에서 공개/친구(초대 전용)를 선택할 수 있고, 공개 방은 목록 참가, 초대 전용 방은 스팀 초대로만 입장하며 두 경로 모두 로비 없이 게임으로 들어간다. 일반 후보 3개와 별도 보스 항목이 동시에 보여도 구분된다. 1~4인에게 같은 진행 단계와 타이머가 표시되고, 중도 합류자는 현재 목표와 자신의 보상 자격을 이해할 수 있다. 일반 배달의 보상 감소·실패, 보스 처치 후 시간 무제한 배송, 우체국 도착 저장, 마지막 배달자의 선택과 팀 공동 컷신을 실제 플레이에서 확인한다.
