# 네트워크 코어 작업 안내

먼저 [담당 기획서](03_네트워크_코어.md)를 읽는다. **서버의 배달·방 규칙, `GameMode`·`GameState`, 배송지 ID 발급·검증과 방별 `SaveGame` 저장 통합을 담당한다.** 1단계는 새 게임·이어하기, 공개/친구(초대 전용) 방 설정과 공개 목록·스팀 초대 즉시 참가, 한 건의 배달과 호스트 타이머, 보상·첫 차 구매 판정, 배달 완료와 우체국 도착 저장을 연결하는 것이다. 별도 로비 레벨은 두지 않는다. 후속 산출물은 **배달 사이클 명세와 클라이언트·서버 데이터 계약 및 저장 기술 명세**다.

코어는 보상 대상·금액과 거래·배달·부활 조건을 판정하고, 플레이어 전투가 제공한 **`PlayerState` 공개 서버 API로만** 개인 돈·총·택배 변경을 요청한다. `PlayerState` 클래스·개인 복제 상태·인벤토리·개인 저장 스냅샷의 직렬화·복원은 플레이어 전투 담당이며 코어는 내부 필드나 배열을 직접 수정하지 않는다. 코어의 방 저장은 개인 스냅샷을 받아 방 진행·차량 상태와 함께 저장하고 복원을 위임하는 책임이다.

호스트에서 실행하는 공격 측 명중 재검증·피해 요청, 플레이어 피해·차량 충돌과 총 습득·드롭·사망 드롭의 서버 처리는 플레이어 전투가 구현한다. AI는 서버에서 적의 피해 수신·체력·보호·사망 처리를 구현한다. 택배는 일반 인벤토리와 별도인 전용 슬롯을 쓰고, 전달은 바닥에 드롭한 뒤 동료가 줍는 방식이다. 코어는 **통합 검증과 성능 측정의 진행·결과 취합을 총괄**하고 각 파트의 검증·수정을 연결한다. 단계별 인수 기준·테스트 시나리오 관리와 단계 통과·체감 품질의 최종 승인은 기획 + PM이 맡는다.
