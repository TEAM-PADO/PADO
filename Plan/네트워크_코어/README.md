# 네트워크 코어 작업 안내

먼저 [담당 기획서](03_네트워크_코어.md)를 읽는다. 1단계는 방 생성·참가, 한 건의 배달과 호스트 타이머, 보상·첫 차 구매 판정, 배달 완료와 우체국 도착 저장을 연결하는 것이다. 후속 산출물은 **클라이언트·서버 데이터 계약 및 저장 기술 명세**다.
