# 화면 흐름·문구 요구사항 — 기획자 기준

기준: [기본 기획](00_기획핵심과_미결정.md) · [배달 상태·저장 규칙](07_배달_상태와_저장_규칙.md). 이 문서는 화면에서 **무엇을 알리고 어떤 행동을 허용할지** 정한다. 화면 배치·시각 디자인·입력 구현은 UI/클라이언트 담당자의 와이어프레임에서 구체화한다.

## 화면 흐름

`방 생성/이어하기 → 우체국 → 배달 후보 지도에서 수락 → 이동·전투 HUD → 현관 노크·수취인 확인/배송 → 완료·보상 → 우체국 복귀 → 다음 수락`이 기본 흐름이다. 실패하면 실패 이유를 보여주고 일반 배달은 후보를 교체하며, 보스 배달은 같은 건을 우체국에서 재수락할 수 있게 한다. 결말을 본 뒤에도 일반 배달과 성장 플레이로 돌아갈 수 있다.

| 장면 | 플레이어가 알아야 하는 정보 | 허용할 행동과 제한 |
|---|---|---|
| 방 생성·이어하기 | 방별 진행과 자기 코인·장비, 일반 저장과 최종 문 앞 체크포인트의 차이 | 새 방은 기본 권총만, 코인·차량 없이 시작. 일반 저장은 우체국에서 재개. 최종 문 앞 체크포인트는 선택 직전 문 앞에서 재개하며 이후 코인·장비·일반 배달 진도가 되돌아감을 불러오기 전에 알림 |
| 우체국 배달 지도 | 일반 목적지 9곳 중 무작위 후보 최대 3개, 거리·목적지·보상·시간 기준, 해금된 보스 배달 별도 항목, 현재 진행 중인 배달 여부 | **후보 지도 확인과 수락은 우체국에 있는 팀원만 가능**. 활성 배달이 있으면 추가 수락 불가. 완료한 일반 목적지도 다음 후보로 바로 재등장할 수 있음 |
| 진행 HUD | 팀의 같은 목표, 목적지 방향, 남은 시간, 택배 소지자, 일반 배달의 현재 예상 보상 또는 보스 처치 단계 | 우체국·상점·도로·배달지 어디에 있어도 진행 상태를 확인. 후보 지도는 우체국에서만 확인 |
| 인벤토리 | 여유 있는 일반 슬롯에 택배·총 등 소지품 표시 | 택배를 동료에게 넘기고, 총을 바닥에 놓아 전달할 수 있음. 차량 탑승에 따른 택배 제한 없음 |
| 총·차 상점 | 개인 코인, 구매 가능 물품, 차의 수리 비용·남은 내구도 | 호스트가 코인·소유권·수리 가능 상태를 확정. 라이플·샷건·스나이퍼는 각각 150코인. 탄약 판매와 총·차 판매는 제공하지 않음. 총 상점 출입이나 구매는 저장 사건이 아님 |
| 일반 배달 현관 | 노크 뒤 수취인 응답, 필요할 때만 문 열기·확인 예외 선택 | 보통 로봇은 직접 나와 확인·수령. ‘충전 중’ 응답일 때만 문 열기 또는 확인 예외 기록 후 완료 선택 제공 |
| 보스 목적지 | 보스 처치 여부와 남은 처치 제한시간 | 보스 처치 전 배송 불가. 제때 처치하면 배송 단계로 바뀌고 시간제한 없음 표시 |
| 완료·실패 결과 | 결과 원인, 지급 보상, 다음 행동 | 완료 후 즉시 저장 완료 표시. 일반 실패 시 후보 교체, 보스 실패 시 같은 배달 재수락 안내. 다음 건 수락은 우체국에서만 가능 |
| 사망·부활 | 현장에 떨어진 소지품, 돈 유지, 우체국 재시작 | 부활 시 기본 권총 지급. 배달 시간이 남아 있으면 다시 합류 가능 |
| 보스 배달 안내 | 보스 목적지가 의심 주소라는 시스템 안내 | 첫 두 보스의 수취인은 평범한 로봇. 최종 배달은 '매우 의심스러운 주소'로 안내하고 반드시 수취인을 확인하라는 지시를 표시 |
| 최종 문 앞 저장점 | 보스 처치 후 택배 소지자가 문 앞에 도착한 선택 전 상태 | 별도 체크포인트 저장 완료를 표시. 이후 일반 저장과 별개로 불러와 다른 결말을 선택할 수 있게 함 |
| 최종 배달·결말 | 수취인의 ‘충전 중’ 응답과 확인/예외 선택 | 실제 택배 전달자만 문 열기를 결정. 지시와 달리 확인 예외도 선택 가능. 팀 전원이 같은 컷신과 결말을 봄. 확인 예외 결말에는 「진실을 외면!」 업적 표시. 문을 열어 약을 주입한 결말에서만 좀비 한 마리가 집 밖으로 나오고 이후 집은 비어 있음 |
| 결말 이후 | 일반 배달 지속과 보스 재등장 | 같은 방에서 코인·장비를 늘리며 일반 배달을 계속하고, 완료한 보스 3마리와 배달 수락 없이 자유 전투할 수 있음을 안내. 자유 전투 보상은 없음 |

## 반드시 구분해서 보여줄 상태

- **일반 배달:** 첫 시간 기준 전/후의 예상 완료 보상, 최종 마감, 실패 여부. 보상은 첫 기준을 넘긴 뒤 한 번만 감소한다.
- **보스 배달:** 보스 처치 제한시간, 처치 성공 뒤 배송 무제한, 실패 시 재수락 가능 여부. 일반 후보와 섞지 않는다.
- **개인 보상 자격:** 수락 시 방에 있었는지와 완료 순간 접속 중인지에 따른 완료 보상 자격. 중도 첫 합류자는 목표에는 참여하지만 그 건의 완료 보상을 받지 않는다.
- **저장 상태:** 배달 완료와 야외→우체국 도착에서 일반 저장이 끝난 시점을 표시한다. 최종 배달에서 보스 처치 후 택배 소지자가 마지막 문 앞에 도착하면 별도 체크포인트 저장 완료를 표시한다. 상점 출입·구매·수리만으로는 저장 완료 표시를 띄우지 않는다. 문 앞 체크포인트를 불러오기 전에는 그 뒤의 성장·진도가 되돌아간다는 사실을 알려준다.
- **후보 지도와 목표 안내:** 후보 선택 지도는 우체국 전용이다. 야외에서는 이미 수락한 목표와 목적지 안내를 계속 볼 수 있어야 한다.

## 문구 톤

우체국 시스템과 수취인은 감정을 크게 드러내지 않는 **담담한 업무 말투의 블랙코미디**를 기본으로 한다. 수취인 확인 예외나 보상 감소도 행정 처리처럼 간결하게 알린다. 일반 배달 화면에는 마지막 인간의 정체를 암시하는 특별한 경고·색상·효과를 넣지 않는다. 최종 배달에는 의심 등급과 수취인 확인 지시를 평소 업무 안내 형식으로 표시한다.

## UI 담당자에게 요청할 결과물

이 요구사항을 바탕으로 우체국 배달 지도, 진행 HUD, 상점·인벤토리, 현관 선택, 완료·실패, 사망·부활, 결말 화면의 **흐름도와 와이어프레임**을 만든다. 각 화면은 혼자와 4인, 일반/보스 배달, 자격 있는/없는 참가자 상태를 모두 표시할 수 있어야 한다.
