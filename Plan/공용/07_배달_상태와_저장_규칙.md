# 배달 상태·저장 규칙표

기준: [기본 기획](00_기획핵심과_미결정.md) · [개발 순서](01_개발순서.md). 이 문서는 네트워크 코어, UI, AI, 플레이어 전투, 레벨디자이너가 **같은 사건을 같은 결과로 처리하기 위한 공동 판정표**다. 규칙이 충돌하면 기본 기획을 우선하고 이 표를 갱신한다.

## 공통 원칙

- 방은 1~4인 리슨 서버이며, 호스트가 배달 상태·타이머·돈·아이템·차량·전투 결과를 최종 판정한다. 클라이언트는 요청과 표시를 담당한다.
- 새 방의 플레이어는 기본 권총만 지급받고 돈·차량 없이 시작한다. 배달 중 처음 합류한 참가자는 우체국에서 등장한다.
- 한 번에 활성화된 팀 배달은 한 건이다. 첫 콘텐츠판의 일반 목적지는 거리별 3곳씩 총 9곳이며 우체국 지도에 무작위 후보 최대 3개를 표시한다. 완료한 목적지도 바로 재등장할 수 있다. 해금된 보스 배달은 별도 고정 항목으로 둔다. 팀원은 같은 목표를 보되 우체국·상점·야외를 자유롭게 오간다.
- 배달 수락은 우체국에 있는 팀원만 할 수 있다. 팀원이 한 명만 돌아와도 다음 건을 수락할 수 있다.
- 우체국과 총 상점 내부는 같은 오픈 지도 안의 좀비 진입 금지 안전 구역이다. **일반 저장 지점은 우체국뿐**이며, 최종 배달에 한해 보스 처치 후 마지막 문 앞에 별도 체크포인트를 둔다. 구역 이동에 로딩이 없으므로 배달 타이머는 계속 흐른다.
- 화폐 단위는 **코인**이다. 완료 보상과 일반 좀비 처치 보상은 별개다. 완료 보상은 수락 당시 방에 있었고 완료 순간 접속 중인 사람에게 각각 같은 금액을 준다. 일반 좀비 처치 보상은 처치자 한 명에게 준다. 보스는 처치 자체에 별도 코인을 주지 않는다.

## 일반 배달 상태

| 현재 상태 | 사건·조건 | 다음 상태와 호스트 판정 | 플레이어에게 보이는 결과 |
|---|---|---|---|
| 후보 | 우체국에 있는 팀원 한 명이 수락 | 진행. 수락자와 배달지, 수락 시 방에 있었던 참가자 집합을 기록하고 타이머 시작. 수락자가 택배를 받음 | 모두에게 목표·남은 시간·택배 소지 상태 표시 |
| 진행 | 첫 시간 기준을 넘김 | 진행 유지, 완료 보상을 정해진 금액만큼 **한 번만** 감소 | 감소한 예상 완료 보상 표시 |
| 진행 | 두 번째 시간 기준을 넘김 | 실패. 완료·보상 불가, 해당 택배를 소지품과 바닥에서 제거, 일반 후보의 해당 자리를 새 후보로 보충 | 실패와 새 후보 표시 |
| 진행 | 목적지에서 택배 소지자가 수취인 확인 또는 허용된 확인 예외로 배송 | 완료. 보상 자격 확인 → 대상자별 보상 지급 → 일반 배달 완료 횟수 증가 → 해당 후보 보충 → 택배 제거 → **즉시 저장** | 팀 전체에 완료·보상·새 후보 표시 |
| 완료 또는 실패 | 팀원 한 명이 우체국으로 돌아옴 | 다음 배달 수락 가능. 야외에서 우체국 안전 구역에 들어온 사건이므로 저장 | 저장 완료 및 다음 수락 가능 표시 |

배달지는 실제 지도 이동시간을 보고 가까운·중간·먼 등급을 붙인다. 첫 테스트 값은 각각 보상 감소/실패 **4/7분, 6/9분, 8/12분**이며, 보상은 **100→70, 150→120, 200→170**이다. 이 값은 확정 밸런스가 아니다.

## 보스 배달 상태

| 현재 상태 | 사건·조건 | 다음 상태와 호스트 판정 | 플레이어에게 보이는 결과 |
|---|---|---|---|
| 잠김 | 첫 보스: 일반 배달 누적 3회. 둘째: 누적 6회와 첫 보스 배달 완료. 셋째: 누적 9회와 둘째 보스 배달 완료(횟수는 첫 테스트 값) | 조건을 모두 만족하면 다음 보스 후보 해금. 해금된 후보는 완료 전까지 고정 | 지도에 일반 후보와 별도 표시 |
| 후보 | 우체국에 있는 팀원 한 명이 수락 | 보스 전투 진행. 보상 자격 집합을 기록하고 처치 제한시간 시작. 보스 처치 불가 보호 해제 | 팀 전체에 보스 목표·남은 시간 표시 |
| 전투 진행 | 제한시간 안에 보스 처치 | 배송 대기. 보스 처치 상태 유지, **배송 시간제한 제거** | 배송 가능·시간제한 없음 표시 |
| 전투 진행 | 처치 제한시간 초과 | 실패. 해당 택배 제거, 보스 체력 최대치 회복·미수락 보호 적용. 보스 후보는 그대로 유지 | 실패·우체국에서 재수락 가능 표시 |
| 최종 배달 배송 대기 | 택배 소지자가 마지막 집 문 앞에 도착 | 노크·선택 전 방·참가자 상태, 최종 택배·전달자·보상 자격, 보스 처치와 시간 무제한 상태를 별도 체크포인트에 저장 | 마지막 문 앞 체크포인트 저장 완료 표시 |
| 배송 대기 | 목적지에서 수취인 확인 또는 허용된 확인 예외로 배송 | 완료. 대상자별 전액 보상 지급 → 보스 진도 갱신 → 택배 제거 → **즉시 저장** | 완료·보상·다음 진행 표시 |

미수락 보스는 접근할 수 있지만 처치할 수 없다. 다른 팀원이 수락 전에 보스 앞에서 기다려도 된다. 보스 체력과 시간은 인원수로 자동 조정하지 않는다. 첫 테스트용 처치 제한시간/보상은 순서대로 **8분/300코인, 10분/400코인, 12분/500코인**이다. 보스 처치 자체에 코인은 지급하지 않는다. 마지막 배달의 수취인 선택은 아래 결말 규칙을 따른다.

두 결말 중 하나를 본 뒤에도 방을 계속 플레이한다. 일반 후보와 배달은 유지한다. 완료한 보스 3마리는 맵에 재등장해 **배달 수락·택배·처치 제한시간 없이** 자유 전투할 수 있고, 처치 뒤에도 재등장한다. 보스의 체력·공격 패턴·수치는 첫 배달 때와 같고 미수락 처치 불가 보호는 적용하지 않는다. 최종 보스는 플레이어가 먼저 공격할 때만 싸운다. 자유 전투에는 보스 배달 보상이나 별도 처치 코인이 없다. 결말 기록은 지우지 않는다.

## 사건별 소유권·예외 처리

| 사건 | 호스트가 확정할 상태 | 협업·표시 책임 |
|---|---|---|
| 배달 수락 | 활성 배달은 하나인지, 수락자가 유효한지, 보상 자격 집합, 택배 소유자, 시작 시각 | UI는 요청·목표 표시, 레벨은 배달지 제공 |
| 배송 | 올바른 목적지인지, 활성 배달과 택배가 일치하는지, 일반 마감 전인지 또는 보스가 처치됐는지, 실제 전달자. 노크 뒤 직접 나온 로봇은 바로 확인, ‘충전 중’ 응답은 문 열기·확인 예외만 허용 | UI·수취인 AI는 응답에 맞는 선택과 반응 제공 |
| 참가자 이탈·재합류 | 수락 당시 자격은 유지. 완료 순간 접속 중일 때만 완료 보상 지급. 수락 후 처음 합류한 참가자는 전투·배송에는 참여 가능 | UI는 현재 목표와 본인 보상 자격 표시 |
| 일반 좀비 처치 | 총격은 발사자, 로드킬은 운전자에게 처치 보상. 일반 좀비만 인원에 따라 수·체력 조정 | AI·전투가 피해·충돌 정보를 제공, UI가 수익 표시 |
| 보스 처치 | 배달 중에는 처치 후 배송 단계 전환. 결말 뒤에는 자유 전투용 재등장. 어느 경우든 처치 자체에는 코인 없음 | AI·전투가 처치 상태 제공, UI는 배송 완료 보상만 표시 |
| 플레이어 사망·부활 | 돈은 유지. 총·택배 등 소지품은 현장에 떨어짐. 우체국에서 기본 권총을 갖고 부활. 배달 타이머는 계속 진행 | 전투가 투하·부활 동작, UI가 소지품 갱신 표시 |
| 바닥 아이템 정리 | 일반 아이템은 3분 후 제거. 진행 중인 배달 택배는 제외하고 배달 완료·실패 때 제거 | 전투·UI가 제거 상태 반영 |
| 차량 상태 변화 | 차가 파괴되지 않았다면 소유자 사망 뒤에도 현장 유지. 파괴 시 탑승자 사망. 구매·수리와 내구도는 방 상태에 반영 | 전투가 운전·좌석·충돌 동작, UI가 비용·내구도 표시 |
| 마지막 수취인 선택 | 매우 의심스러운 주소이므로 반드시 확인하라는 시스템 지시를 먼저 표시. 실제 택배 전달자만 ‘충전 중’ 응답 뒤 문 열기를 결정. 열면 인간에게 약을 주입하고 변한 좀비 한 마리가 집에서 나오며 이후 집 안은 비어 있음. 확인 예외면 「진실을 외면!」 업적·다른 결말이며 집에서 좀비가 나오지 않음. 어느 결말 뒤에도 방은 계속됨 | UI가 선택 입력, AI·연출이 팀 전체에 같은 결과 표시 |

## 저장 사건과 복원 범위

| 사건 | 저장 여부 | 저장·재개 시 의미 |
|---|---|---|
| 배달 완료 직후 | **일반 저장** | 완료 진도, 보상 지급, 다음 일반 후보 또는 보스 진행을 같은 저장 결과에 반영 |
| 야외에서 우체국 안전 구역에 도착 | **일반 저장** | 도착한 팀원 한 명으로 방 전체 상태 저장. 같은 안전 구역에 계속 서 있는 동안 반복 저장하지 않음 |
| 최종 보스 처치 후 택배 소지자가 마지막 문 앞에 도착 | **별도 체크포인트 저장** | 노크·선택 전 방·참가자 상태와 최종 택배·전달자·보상 자격, 보스 처치 완료·배송 시간 무제한을 보존. 이후 일반 저장으로 덮어쓰지 않음 |
| 총 상점 출입, 구매·수리, 아이템 이동, 배달 수락·실패, 참가자 퇴장 | **그 사건만으로 저장하지 않음** | 다음 완료·우체국 재도착 또는 최종 문 앞 체크포인트 전에 종료하면 마지막 일반 저장 상태로 돌아감 |

일반 저장 데이터에는 방별 완료 횟수·해금·후보·결말 기록, 참가자별 코인과 인벤토리에 보관한 총, 파괴되지 않은 차량의 종류·소유·남은 내구도를 넣는다. 결말 기록이 있는 방에서는 일반 배달과 완료 보스의 자유 전투를 재개한다. **일반 저장은 진행 중 배달의 타이머·보스 체력·택배 소지, 바닥 아이템, 플레이어의 야외 위치를 재개하지 않는다.** 일반 저장으로 방을 다시 열면 모두 우체국에서 시작하고 멀쩡한 차는 남은 내구도로 우체국 앞에 놓는다. 완료된 배달은 다시 지급하지 않으며, 진행 중이던 배달은 저장된 후보에서 처음부터 다시 받는다. 호스트가 방을 열어 둔 동안의 재합류에는 저장본이 아닌 현재 방 상태를 사용한다.

최종 문 앞 체크포인트는 **선택 전의 방 전체 상태를 별도로 보존**한다. 명시적으로 불러오면 택배 전달자를 포함한 팀이 마지막 문 앞에서, 보스가 처치되고 배송 시간제한이 없는 상태로 재개해 다른 결말을 선택할 수 있다. 체크포인트 뒤에 번 코인·구매한 장비·완료한 일반 배달 진도는 체크포인트 시점으로 되돌아간다. 결말 뒤 일반 저장을 여러 번 해도 체크포인트는 남는다. 최종 배달 보상은 선택한 진행에서 완료할 때 한 번만 지급한다.

**주의할 플레이 경험:** 총 상점이나 차량 상점에서 구매·수리한 뒤 다음 저장 전에 게임을 종료하면 그 변경은 되돌아간다. 일반 배달 실패 직후 우체국에 돌아오기 전에 종료해도 실패에 따른 후보 교체가 마지막 일반 저장본으로 되돌아갈 수 있다. 최종 문 앞 체크포인트를 불러오면 이후 성장도 되돌아간다. UI는 저장 완료와 불러오기 시 되돌아갈 범위를 분명히 보여준다.

## 아직 수치·콘텐츠 결정이 필요한 것

보스 배달 3개를 여는 일반 배달 완료 횟수의 첫 테스트 값은 3·6·9회이며, 뒤 보스는 앞 보스 배달 완료도 필요하다. 일반 목적지 ID와 초반 경제값은 [배달 콘텐츠·진행표](09_배달_콘텐츠_진행표.md)와 [경제·밸런스 초안](10_경제_밸런스_초안.md)에 있다. 라이플·샷건·스나이퍼는 첫 테스트에 각각 150코인이다. 실제 건물 위치, 총·차의 개별 성능, 추가 차량 가격, 일반 좀비 이외 적의 처치 수익, 좀비·보스 전투 수치와 결말 후 보스 재등장 간격은 담당 파트의 상세 명세와 테스트로 확정한다. 보스 처치 자체에는 별도 코인이 없다.
