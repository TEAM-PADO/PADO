# 경제·밸런스 초안 — 첫 플레이 테스트 값

기준: [기본 기획](00_기획핵심과_미결정.md) · [배달 콘텐츠·진행표](09_배달_콘텐츠_진행표.md). 아래 값의 화폐 단위는 **코인**이다. 첫 테스트를 시작하기 위한 기획값이며, 실제 이동시간·전투시간·1~4인 결과를 보고 조정한다.

게임 수치·가격·감액·처치 보상·아이템 정리 시간과 택배 예외는 기획+PM이 확정한다. 코어는 서버에서 배달 보상 자격·금액과 처치 보상을 판정하며, 플레이어 담당자가 소유한 `PlayerState`의 **공개 서버 API**로 개인 돈·총·택배 변경을 요청한다. 돈·인벤토리·개인 장비의 복제 및 저장 스냅샷 직렬화·복원은 플레이어 담당이고, 코어는 내부 변수·배열·직렬화 코드를 직접 수정하지 않는다. UI는 서버 응답과 복제된 `GameState`·`PlayerState`를 표시한다.

## 시작 상태와 수입

| 항목 | 첫 테스트 값 | 적용 규칙 |
|---|---:|---|
| 새 방 시작 돈 | 0 | 방마다 별개의 진행. 다른 방의 돈을 가져오지 않음 |
| 시작 장비 | 기본 권총 1정 | 시작 차량 없음. 사망·부활 때도 기본 권총 다시 지급 |
| 약한 일반 좀비 처치 | 처치자에게 20 | 기본 권총으로 우체국 근처에서 잡을 수 있어야 함. 로드킬은 운전자, 동승 사격은 발사자가 받음 |
| 일반 배달 가까움 | 각 자격자에게 100, 늦으면 70 | 수락 시 방에 있었고 완료 순간 접속 중인 팀원에게 동일 지급 |
| 일반 배달 중간 | 각 자격자에게 150, 늦으면 120 | 첫 시간 기준 초과 시 30 한 번 감소 |
| 일반 배달 멂 | 각 자격자에게 200, 늦으면 170 | 최종 마감 초과 시 완료·보상 불가 |
| 보스 배달 1·2·3 | 각 자격자에게 기본 300·400·500 | 제한시간 안에 보스 처치 후 배송. 둘째에서 수취인 확인 생략 시 기본 400에서 추가 차감하며 차감액·비율 미정. 실내 충전 중 로봇 확인 시 정상 보상 |
| 보스 처치 자체 | 0 | 보스 배달 완료 보상만 지급하고, 처치자에게 별도 보상 없음 |

## 첫 구매와 수리

| 항목 | 첫 테스트 값(코인) | 의도 |
|---|---:|---|
| 첫 차량 구매 | 200 | 약한 좀비 10마리를 처치하면, 일반 배달 보상 없이도 살 수 있음 |
| 라이플·샷건·스나이퍼 | 각 150 | 기본 권총 이후 세 총 중 골라 구매. 차량과 총 중 무엇을 먼저 살지 선택 가능 |
| 첫 차량 수리 | 손상량에 비례, 최대 70 | 내구도를 최대치까지 회복하는 비용의 상한. 손상이 적으면 더 싸게 수리 |
| 탄약 | 0 | 탄약 구매 없음. 재장전 시 예비 탄약 소모 없이 탄창을 계속 채움 |

첫 차량의 테스트용 수리 계산은 `올림(70 × 잃은 내구도 ÷ 최대 내구도)`로 둔다. 손상이 없으면 수리하지 않고 0을 받는다. 내구도가 50% 남았다면 35, 0%가 되기 직전이라면 최대 70에 가깝다. **파괴된 차량은 수리할 수 없고 새로 구매**한다. 실제 차량 종류별 최대 내구도와 수리비 기준값은 플레이어 전투·네트워크 담당자가 제안하고 기획자가 검토한다.

## 반복 플레이에서 지킬 경제 규칙

- 배달 완료 보상은 자격 있는 팀원 **각자**에게 같은 금액을 준다. 좀비 처치 보상은 처치자 한 명에게만 준다. 한 차에 함께 타도 개인 돈은 합치지 않는다.
- 코어는 수락 시 참가자 명단을 기록하고 완료 순간 접속 중인 명단의 참가자에게만 완료 보상을 지급한다. 수락 당시 참가자가 이탈 후 재접속하면 자격을 유지하고, 수락 후 처음 합류한 참가자는 해당 건의 완료 보상에서 제외한다. UI가 이 자격이나 지급액을 독자 판정하지 않는다.
- 총을 바닥에 떨어뜨려 동료에게 줄 수 있지만 차의 소유권은 넘기지 않는다. 총·차 판매 기능은 두지 않는다.
- 택배는 전용 슬롯으로 운반하고 동료에게 전달할 때 바닥에 떨어뜨린 뒤 동료가 줍는다. 총 습득·드롭과 사망 아이템 드롭의 서버 처리는 플레이어 담당이 구현하고 `PlayerState`를 변경한다. 코어는 배달 택배 소지 여부·현재 배달 유효성을 검증하고 공개 서버 API로 생성·제거를 요청한다.
- 돈은 사망해도 유지하고, 구매한 차가 파괴되면 새 차를 사야 한다. 무료 기본 차량은 첫 구현에 두지 않는다.
- 총기의 탄약은 구매하거나 저장할 자원이 아니다. 탄창 용량과 재장전 동작은 유지하지만 예비 탄약은 무제한이다.
- 구매·수리 자체는 저장 사건이 아니다. 다음 배달 완료 또는 우체국 재도착 전에 방을 종료하면 마지막 일반 저장본으로 돌아갈 수 있다. 최종 배달에서만 보스 처치 후 마지막 문 앞에 별도 체크포인트를 만들며, 이를 나중에 불러오면 그 뒤에 번 코인·산 장비도 문 앞 시점으로 되돌아간다.
- 코어는 방 진행·후보·해금·차량 상태와 함께 `PlayerState`에서 받은 개인 저장 스냅샷을 저장한다. 일반 재개는 진행 중 배달을 초기화하고 완료 진도를 복원하며, 최종 문 앞 체크포인트의 별도 복원 규칙은 유지한다.
- 1~4인에 따라 일반 좀비의 수와 체력만 조정한다. 배달 시간·보스 체력·보스 보상은 인원수로 자동 변경하지 않는다.

## 첫 테스트에서 측정할 것

1. 기본 권총으로 약한 좀비 10마리를 처치해 첫 차를 사기까지 걸리는 시간과 사망 횟수. 돈이 0이고 차가 없는 상태에서 진행이 막히면 수치를 조정한다.
2. 첫 차를 산 뒤 가까운·중간·먼 배달을 1~4인으로 완료하는 실제 시간. 기획의 보상 감소/실패 기준인 4/7분, 6/9분, 8/12분이 도로·전투·현관 상호작용에 맞는지 확인한다.
3. 차를 잃은 뒤 기본 권총으로 다시 구매 비용을 모을 수 있는지, 수리와 재구매 사이에 의미 있는 선택이 있는지 확인한다.
4. 함께 탄 팀원과 각자 차를 산 팀원의 수입 격차가 진행을 막는지 확인한다. 필요한 경우 적 처치 수익이나 차 가격을 조정한다.
5. 1/2/4인의 호스트·클라이언트에서 각 플레이어의 돈·인벤토리 표시가 서버 확정 상태와 일치하고, 이탈 후 복귀자는 보상 자격을 유지하며 최초 후발 합류자는 제외되는지 확인한다. 저장·재개와 체크포인트 복원 후 개인 스냅샷·방 진행이 일치하고 보상이 중복 지급되지 않는지도 확인한다. 기획+PM은 인수 기준과 시나리오를 관리하고 각 구현 담당은 검증 근거를 제출한다.

## 이후 채울 값

라이플·샷건·스나이퍼의 개별 성능, 추가 차량의 종류·성능·가격, 일반 좀비 이외 적의 처치 수익, 차량별 수리비 상한은 해당 콘텐츠를 구현하기 전에 정한다. 세 총의 첫 테스트 가격은 **각 150코인**이다. **보스 처치에 별도 코인을 지급하지 않는 규칙은 결말 후 자유 전투에도 적용**한다. 첫 테스트 값을 바꿀 때는 이 표와 기본 기획의 값을 함께 갱신한다.
