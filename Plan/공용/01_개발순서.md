# 좀비세상 우편배달 — 개발 순서

이 문서는 [기본 기획](00_기획핵심과_미결정.md)을 구현하기 위한 작업 순서다. 확정된 게임 규칙은 기본 기획을 따른다. 아래 단계는 일정이나 인원 배분이 아니라, 팀이 함께 플레이하며 다음 단계로 넘어갈 수 있는 통합 기준이다.

## 공통 기준

- 첫 구현은 1~4인 리슨 서버다. 방장이 게임 상태를 판정하고 방별 진행을 저장한다.
- 새 방은 플레이어마다 기본 권총만 주고 돈·차량은 지급하지 않는다. 배달 중 새로 합류한 참가자는 우체국에서 시작한다.
- 한 방에서 진행 중인 팀 배달은 한 건이다. 첫 콘텐츠판 일반 목적지는 거리별 3곳씩 총 9곳이며, 우체국 지도에 그중 무작위 후보 최대 3개를 표시한다. 완료한 목적지도 다음 후보로 바로 다시 나올 수 있다. 해금된 보스 배달은 별도 고정 항목이다.
- 팀원 한 명이 우체국에 있을 때만 다음 배달을 수락할 수 있다. 보스는 일반 배달 누적 3·6·9회 완료 시 순서대로 해금한다(첫 테스트 값).
- 우체국 내부·차량 상점·총 상점·배달지는 하나의 오픈 지도에 있으며 플레이 중 이동에 따른 레벨 전환이 없다. 우체국 내부와 총 상점 내부는 좀비 진입 금지 안전 구역이고, 두 건물 사이 도로·보도에는 좀비가 활동한다. 저장 구역은 우체국 내부만이다.
- 일반 저장은 **배달 완료 직후**와 **야외에서 우체국 안전 구역에 도착했을 때** 발생한다. 일반 저장으로 방을 다시 열면 모두 우체국에서 시작하고 완료한 배달 진도를 유지한다. 진행 중인 배달은 처음부터 다시 받는다. 최종 배달만 보스 처치 뒤 마지막 문 앞에 별도 체크포인트를 두어 선택 직전부터 다시 시작할 수 있다.
- 수치와 콘텐츠 규모는 플레이 테스트로 조정한다. 첫 테스트용 시간·보상 값은 기본 기획의 표를 사용한다.

## 1단계 — 배달 한 건이 끝까지 돌아가는 통합판

**목표:** 새 방에서 기본 권총으로 약한 좀비를 처치해 첫 차를 사고, 우체국에서 일반 배달을 수락한다. 차로 이동하며 좀비를 돌파해 수취인에게 배송·보상을 받고, 팀원 한 명이 우체국으로 돌아오면 다음 건을 고를 수 있다.

| 파트 | 이 단계에서 필요한 것 |
|---|---|
| 레벨디자이너 | 한 지도에 이어진 우체국 내부·앞마당·첫 차량을 살 수 있는 상점·총 상점 자리·야외 도로·가까운 배달지 1곳·약한 좀비 구역. 로딩 없이 이동시간을 측정할 수 있는 임시 동선 |
| 네트워크 코어 | 방 생성·참가, 한 건의 배달 상태와 호스트 타이머, 완료 판정·완료 후 다음 후보 1개·완료/처치 보상, 첫 차 구매와 개인 돈 판정, 플레이어와 차량의 최소 동기화, 배달 완료·우체국 도착 저장 |
| AI 프로그래머 | 약한 일반 좀비의 추적·공격·사망·재생성. 1~4인에 따른 수·체력 조정의 기본 구조 |
| 플레이어 전투 | 3인칭 이동·기본 권총, 첫 차 구매 후 운전·승하차·로드킬, 사망 시 아이템 투하와 우체국 부활의 기본 흐름 |
| UI/클라이언트 시스템 | 첫 차 구매·소지금, 배달 후보 1개와 완료 후 다음 후보·수락·진행시간·목표 안내, 인벤토리의 택배 표시, 배송 상호작용, 완료·보상 표시 |

**통과 기준:** 새 방의 기본 권총·돈 0·차량 없음에서 시작해 약한 좀비 10마리의 처치 수익으로 첫 차를 사고, 혼자와 2인 이상이 각각 한 건을 끝까지 완료한다. 수락 순간부터 타이머가 흐르고, 자격 있는 참가자만 동일한 완료 보상을 받는다. 완료 직후 방을 종료해 다시 열어도 진도와 보상이 유지되며 플레이어는 우체국에서 시작한다.

## 2단계 — 실패, 성장, 합류와 이어하기

**목표:** 의도하지 않은 종료나 실패가 발생해도 방의 상태가 규칙대로 이어지고, 차와 총을 사며 반복 배달할 수 있다.

| 파트 | 이 단계에서 필요한 것 |
|---|---|
| 레벨디자이너 | 같은 지도 안의 가까운·중간·먼 배달지 묶음, 총·차 상점 출입·구매·수리 동선, 무자본 회복용 약한 좀비 구역, 우체국 복귀 동선 |
| 네트워크 코어 | 일반 후보 최대 3개 관리와 실패 후 보충, 보상 감소·최종 실패, 중도 합류·재접속, 전체 총·차 구매·수리, 방별 돈·총·차 저장, 차량 내구도 복원, 저장 시점 사이의 종료 처리 |
| AI 프로그래머 | 야외 일반 좀비 재생성, 위치·인원에 따른 밀도 조정, 차량과 플레이어를 대상으로 한 안정적인 적 판정 |
| 플레이어 전투 | 동승 사격·좌석 변경, 총 줍기·전달, 차량 수리·파괴, 차량 안 사망과 소유자 사망 후 차량 유지 |
| UI/클라이언트 시스템 | 상점·인벤토리·좌석·차량 내구도, 보상 감소·실패 안내, 합류자에게 현재 목표와 보상 자격 표시 |

**통과 기준:** 시간 초과, 전원 사망, 차량 파괴, 배달 중 합류·재합류, 방 종료 후 재개를 실험한다. 이 단계에서는 배달 진행 중 종료했다면 완료 진도는 보존하고 해당 배달을 처음부터 다시 받는다. 3단계 최종 문 앞 체크포인트만 별도 예외다. 바닥의 일반 아이템은 3분 후 사라지며 진행 중인 택배는 배달 종료 전까지 유지된다.

## 3단계 — 보스 배달과 결말

**목표:** 일반 배달 누적 횟수와 앞 보스 완료 조건으로 보스 배달 3개가 순서대로 열리고, 마지막 선택 뒤에도 같은 방에서 일반 배달과 완료한 보스 3마리의 자유 전투를 계속할 수 있다.

| 파트 | 이 단계에서 필요한 것 |
|---|---|
| 레벨디자이너 | 서로 다른 보스 목적지 3곳과 전투 공간, 중심부 최종 보스·마지막 인간 집, 복선이 되는 일반 수취인 배치 |
| 네트워크 코어 | 보스 해금·고정 후보·재도전, 보스 처치 제한시간과 배송 단계 전환, 마지막 문 앞 체크포인트의 별도 보존·불러오기, 최종 선택·결말·업적의 방 상태 저장 |
| AI 프로그래머 | 보스 3종 행동, 미수락 시 처치 불가, 실패 시 체력 회복, 로봇 수취인 응답과 최종 장소 연동 |
| 플레이어 전투 | 보스전 중 사망·재진입, 다수 플레이어와 차량 전투의 마무리, 전투 피드백과 밸런스 조정 |
| UI/클라이언트 시스템 | 일반 후보와 별도인 보스 항목, 처치 제한시간·이후 무제한 배송 표시, 마지막 문 앞 체크포인트·되돌리기 안내, 문 열기/확인 예외 선택, 전원 공유 컷신·업적 |

**통과 기준:** 보스를 시간 안에 잡으면 배송 시간이 무제한이 되고, 못 잡으면 즉시 실패·체력 회복 후 재도전할 수 있다. 최종 문 앞 체크포인트를 불러오면 팀이 선택 직전으로 돌아가 다른 결말을 볼 수 있으며, 체크포인트 뒤의 성장·진도는 되돌아간다. 마지막 배달자는 ‘충전 중’ 응답 뒤 수취인 확인 여부를 결정하고 팀 전원이 같은 결말을 본다. 결말 뒤에도 일반 배달을 받고, 보스 배달 재수락 없이 재등장한 보스와 자유 전투할 수 있다.

## 통합할 때 먼저 맞출 계약

1. **배달 상태:** 후보 → 수락/진행 → 보상 감소(일반) 또는 보스 처치 완료(보스) → 완료/실패. 상태 전환과 시간 기준은 네트워크 코어가 판정한다.
2. **보상 자격:** 수락 시 방에 있었고 완료 순간에도 접속 중인 플레이어 목록을 네트워크 코어가 관리한다. 중간에 나갔다 돌아온 사람도 자격을 유지한다.
3. **상호작용:** 수락·택배 이동·배송·상점·문 열기는 클라이언트가 요청하고 호스트가 검증해 결과를 전파한다.
4. **전투 결과:** 적 처치·차량 충돌·아이템 투하·부활의 최종 결과는 호스트가 확정한다. 좀비 행동은 AI, 입력과 조작감은 플레이어 전투가 담당한다.
5. **저장 경계:** 배달 완료와 우체국 도착에서 완료 진도·돈·인벤토리의 총·파괴되지 않은 차와 내구도를 한 묶음으로 저장한다. 재개 시 바닥 아이템은 복원하지 않는다.
