# 플레이어 전투 작업 안내

먼저 [담당 기획서](05_플레이어_전투.md)를 읽는다. 이 문서는 현재 구현 상태를 기록하므로, 미구현 작업은 공용 개발 순서와 작성 요청을 함께 확인한다. 1단계는 기본 권총·첫 차·로드킬·사망과 부활의 기본 흐름이다. 후속 산출물은 **플레이어·총기·차량 조작 및 수치 명세**다.

**`PlayerState` 클래스·개인 돈·인벤토리·장비의 복제 상태, 공개 서버 API와 개인 저장 스냅샷의 직렬화·복원을 소유한다.** 코어는 배달·거래·보상 자격과 지급액을 판정하고 API로 변경을 요청하며, 방 저장 호출·파일 통합은 코어가 맡는다. 총 습득·드롭·사망 드롭은 플레이어 전투가 서버에서 검증·처리한다. 일반 아이템 슬롯과 별도로 택배 전용 슬롯을 두고, 택배 전달은 바닥에 떨어뜨린 뒤 동료가 줍는 방식으로 구현한다. 이 내용은 구현 목표이며 현재 완료 상태를 뜻하지 않는다.

공격 측 명중 재검증·피해 요청, 플레이어 피해·차량 충돌은 플레이어 전투가 구현하고 서버의 적 피해 수신·체력·보호·사망 처리는 AI에 연결한다. 현재 방 재접속은 방이 유지한 상태/스냅샷을 연결하고, 방 종료 후 불러오기는 선택한 저장본을 적용한다.
