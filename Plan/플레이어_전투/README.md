# 플레이어 전투 작업 안내

먼저 [담당 기획서](05_플레이어_전투.md)를 읽는다. 이 문서는 현재 구현 상태를 기록하므로, 미구현 작업은 공용 개발 순서와 작성 요청을 함께 확인한다. 1단계는 기본 권총·첫 차·로드킬·사망과 부활의 기본 흐름이다. 후속 산출물은 **플레이어·총기·차량 조작 및 수치 명세**다.
