# 레벨 레퍼런스

레벨디자이너가 지도·건물·도로·분위기 참고 자료를 이곳에 모은다. 현재 참고 파일은 없다. 새 자료를 추가하면 출처와 적용할 구역을 함께 기록한다.

적용 구역에는 도보·차량 동선, 현관·수취인 등장점, 스폰 가능/금지 구역, 안전 구역·우체국 저장 트리거, NavMesh와 연결할 공간을 명시한다. 배송지를 참조할 때는 코어가 발급한 `DeliveryLocationId`를 사용하고, 신규 ID는 기획의 배송지 추가 요청과 코어 발급을 거쳐 반영한다. 참고 이미지의 픽셀 위치는 실제 월드 위치·상호작용 범위·배달 판정으로 사용하지 않는다.
