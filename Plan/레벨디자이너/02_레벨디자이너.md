# 레벨디자이너 — 도시와 배달 동선

기준: [기본 기획](../공용/00_기획핵심과_미결정.md) · [개발 순서](../공용/01_개발순서.md)

## 맡는 결과

1~4인이 우체국에서 출발해 같은 배달 목표를 향해 달리고, 전투 후 현관에서 배송하는 공간을 만든다. 우체국 내부·앞마당·차량 상점·총 상점·배달지와 도로를 **하나의 오픈 지도**에 배치한다. 플레이 중 이 장소들 사이를 이동할 때 별도 레벨 전환이나 로딩 화면이 없다. 우체국과 총 상점이 있는 중심부는 전체 맵의 일부이며, 도로와 건물은 바깥 도시 구역까지 이어져야 한다.

레벨디자이너는 실제 월드 위치·공간·동선과 플레이 측정값을 제공한다. 거리 등급·제한시간·보상 변경은 측정 근거를 붙여 제안하고 기획자가 확정한다. 네트워크/코어는 확정된 값을 배달 데이터에 반영하며, 레벨디자이너는 승인된 목표에 맞춰 도로와 공간을 조정한다.

배송지의 **공간적 실체와 Anchor/Actor 배치**는 레벨 담당이다. 네트워크/코어가 발급한 `DeliveryLocationId`를 각 Anchor/Actor에 할당하고, 배송 상호작용점·문·수취인 등장점·지도 마커의 실제 위치를 연결한다. ID 생성·변경·폐기와 배달 정의 데이터는 코어가 관리한다. 새 배송지는 기획의 추가 요청을 거쳐 코어에서 ID를 받은 뒤 배치한다.

## 중심부 배치와 분위기

- 우체국은 5층짜리 서양식 현대·근미래 도심 건물 1층에 두고, 맞은편 비슷한 규모의 건물 1층에 총 상점을 둔다. 두 출입구는 바로 맞닿지 않게 도로와 보도를 사이에 두고, 이동 중 좀비를 만나거나 피할 만한 거리를 확보한다. 콘크리트·금속·유리 위주의 실사 질감으로, 고전적인 아치나 지나치게 예쁜 외관은 피한다.
- 차량 상점은 우체국과 총 상점이 마주 보는 거리에서 조금 떨어진 곳에 둔다. 실제 거리는 차량 이동시간을 측정하며 정한다.
- 우체국에서 바라보이는 표지판 쪽 직선도로 끝에 거대 좀비 보스를 둔다. 보스의 몸이 도로 너머 시야를 가리고 그 직진 길목을 통과할 수 없음을 거리 전경에서도 알아볼 수 있게 한다.
- 주변 건물은 대부분 비어 있고 사용 흔적이 적다. 깨진 유리, 덧댄 판자, 먼지, 잡초, 흩어진 물건 등으로 아포칼립스의 방치감을 드러내되 건물과 도로는 이동 가능하게 남긴다.
- 간판·현수막·도로 표지에는 글자를 넣지 않는다. 우체국과 총 상점은 각각 우편·총기 그림 표시와 매장 내부 소품으로 구별한다.
- 부드러운 낮 햇빛과 약한 흐림이 있는 나른한 오후를 기본 분위기로 삼는다. 정확한 평면 배치와 도로 폭은 플레이 테스트로 확정한다.

## 작업 묶음

| 단계 | 산출물 |
|---|---|
| 1. 배달 한 건 | 한 지도에 이어진 우체국·총 상점 내부 안전 구역, 두 건물 사이 좀비가 활동하는 도로·보도, 우체국 앞마당 차량 공간·첫 차 구매가 가능한 차량 상점·가까운 일반 배달지 1곳과 연결 도로. 차량 이동시간을 잴 수 있는 임시 맵 |
| 2. 반복 플레이 | 같은 지도 안의 가까운·중간·먼 목적지 풀, 차량/총 상점 출입·구매·수리 동선, 막힘 없는 우체국 복귀 경로, 무자본 상태에서 기본 권총으로 돈을 벌 수 있는 구역 |
| 3. 보스와 결말 | 보스 목적지와 전투 공간 3곳, 첫 보스 로봇 수취인 등장 공간, 둘째 충전 중 로봇의 실내 확인 공간, 셋째 마지막 인간 집·문 앞 체크포인트, 문을 연 결말의 좀비 출구와 이후 빈 실내 |

## 배치 규칙

- 우체국 내부와 총 상점 내부는 같은 지도 안의 별도 안전 구역이며 좀비가 들어오지 않는다. 두 건물 사이 도로·보도와 출입구 바깥은 안전 구역 밖으로 두어 일반 좀비가 이동·공격할 수 있게 한다. 우체국 현관 경계는 야외에서 우체국에 도착한 저장 판정에 사용하지만, 총 상점 출입은 저장을 발생시키지 않는다. 전원 집결이나 강제 이동을 요구하는 문·도로 구조를 만들지 않는다.
- 총 상점은 우체국 맞은편 1층에 두되, 두 출입구 사이에 좀비와 조우할 수 있는 횡단 동선을 확보한다. 차량 상점은 중심부에서 조금 떨어진 같은 지도 안의 실제 건물 또는 매장 자리에 둔다. 상점 입장·퇴장과 구매·수리에도 별도 레벨 전환을 두지 않는다.
- 팀원 한 명만 우체국으로 돌아와도 다음 배달을 받을 수 있다. 입구와 배달 선택 지점 사이의 동선이 이를 방해하지 않아야 한다.
- 생존자 한 명의 우체국 내부 안전 구역 도착은 사망한 팀원 전원의 부활 조건이기도 하다. 앞마당·총 상점과 구분되는 내부 경계를 제공하고, 전멸 자동 부활과 생존자 복귀 부활에 사용할 새 몸 등장 공간을 내부에 확보한다. 데이터가 돌아와 대기하고 새 몸에 들어가는 연출이 가능하도록 1~4인의 부활 공간과 출입 동선을 확보한다.
- 보스 앞에 미리 가서 기다리는 전략을 허용한다. 보스 구역 접근을 수락 여부로 막지 않는다. 첫 결말 전 미수락 시 처치 불가 판정은 AI·네트워크 쪽에서 처리한다. 결말 뒤에는 완료한 보스 3마리가 다시 등장해 자유 전투할 수 있도록 각 전투 공간을 계속 사용한다.
- 최종 보스는 우체국 밖으로 나오면 보이는 중심부에 두고, 플레이어가 먼저 건드리기 전에는 위험하지 않게 AI와 함께 검증한다.
- 보스 배달 3곳 각각 문 앞의 팀 재개 위치와 접근 가능한 차량 재개 지점을 제공한다. 처치 직후 저장을 불러왔을 때 팀과 차량이 건물·서로의 충돌에 끼지 않고 배송 상호작용에 접근할 수 있어야 한다. 재개 위치는 배송지 ID에 연결하고 저장·재개 판정은 코어가 맡는다.
- 최종 배달에서 보스 처치 뒤 택배 소지자가 문 앞에 도착하면 선택 전 체크포인트를 만들 수 있도록 현관 앞 상호작용 지점과 팀 재개 위치를 제공한다. 문을 열어 약을 주입한 결말에서는 변한 좀비 한 마리가 집 밖으로 나오고 이후 집 안은 비어 보이게 한다. 확인 예외 결말에는 이 좀비 등장 연출을 적용하지 않는다.
- 표지판 쪽 보스 차단 구간은 접근 전에도 보스의 크기와 막힌 길이 읽혀야 한다. 보스 앞까지 갈 수는 있지만, 보스가 길을 막는 동안 그 직진 도로를 관통해 지나갈 수 없게 동선과 충돌 범위를 검증한다.
- 차량이 여러 대 있을 수 있고 파괴되지 않은 차는 소유자 사망 후에도 현장에 남는다. 도로·차량 상점 앞·목적지 앞 공간은 1~4인이 함께 타거나 각자 차를 타는 경우를 모두 수용해야 한다. 총 상점에는 보행 접근과 상호작용 공간을 확보한다.
- 일반 배달은 거리 등급별로 실제 차량 이동시간을 측정하고 주행·전투·현관 배송 시간을 나누어 기록한다. 기획의 4/7분, 6/9분, 8/12분 기준은 첫 테스트 값이다. 측정 결과에 따라 거리 등급·제한시간 변경을 제안하고, 기획자의 확정 뒤 네트워크/코어가 배달 데이터에 반영한다. 도로 길이·접근 동선은 승인된 목표에 맞춰 레벨디자이너가 조정한다.
- 모든 배송지 Anchor/Actor에는 코어가 발급한 유효한 ID 하나를 할당한다. ID 누락·중복 배치·정의 없는 ID는 레벨 검수 오류로 기록하고 코어와 함께 수정한다. 서버 시작 시 코어의 Anchor/배달 정의 매칭 검증을 통과한 배송지만 후보가 된다. 레벨에서 ID 문자열이나 열거값을 임의로 만들지 않는다.
- 일반 좀비의 스폰 가능·금지·밀도 영역과 안전 구역 진입 금지 영역을 배치한다. 실제 활성화·재생성·밀도 조절은 AI가 담당하며, 레벨은 플레이어 주변 스폰을 피할 수 있는 공간과 AI가 사용할 구역 정보를 제공한다.
- NavMesh 범위·이동 불가 구역을 설계하고 AI·차량이 반복해서 끼는 지형을 수정한다. 차량 회전·정차·파괴 후 도보 복귀, 부활 후 목적지 재합류, 보스 전투장의 차량 진입·엄폐·재진입·탈출을 1/2/4인으로 검수한다. 스폰 밀집 지점과 지나치게 넓은 내비게이션 영역도 함께 점검한다.
- 총 구매·차량 구매·수리의 상호작용 위치와 우체국 저장 트리거의 실제 경계·진입 동선을 배치한다. 트리거는 코어에 도착 사실을 전달하며 저장 여부·부활·배달 결과를 자체 판정하지 않는다.

## 제공할 공간 데이터

| 제공 항목 | 레벨 산출물 |
|---|---|
| 배송지 Anchor/Actor | 코어 발급 `DeliveryLocationId`, 월드 Transform, 배송 상호작용 범위, 문 위치 |
| 수취인·지도 마커 위치 | 수취인 등장·퇴장점과 현관·지도 마커의 실제 월드 위치 |
| 공간 태그와 전투장 | 가까운/중간/먼 공간 구분, 보스 전투장과 차량 진입·엄폐·재진입·탈출 동선 |
| 일반 좀비 구역 | 스폰 가능·금지·밀도 영역, 안전 구역 진입 금지 경계 |
| 안전·저장 구역 | 우체국·총 상점 실내 경계, 우체국 저장 트리거, 부활 위치 |
| 상점·이동 영역 | 총·차량 구매 및 수리 위치, 도로 폭, NavMesh 범위와 이동 불가 구역 |

## 다른 파트에 제공할 것

- 네트워크 코어와 UI에 건물·문·상호작용점의 실제 월드 위치, 제작용 명칭, 우체국 안전 구역 경계와 도착·부활 위치, 차량/총 상점 위치 등 공간 정보를 제공한다. **ID 발급·배달 정의·서버 매칭 검증·배달 규칙·진행 사이클은 네트워크/코어 담당**, 발급된 ID의 Anchor/Actor 할당과 실제 배치는 레벨 담당이다. 레벨은 배송 완료·보상·개인 인벤토리·저장 형식을 구현하지 않는다.
- 거리별 경로와 실제 소요시간, 거리 등급·제한시간 변경 제안을 기획자와 네트워크/코어에 제공한다. 거리 등급·제한시간·보상은 기획자가 확정하고 네트워크/코어가 반영한다.
- 게임 지도용 월드 좌표를 UI에 제공한다. 월드 좌표를 지도 좌표로 변환하고 핀을 표시하는 기능은 UI 담당이며, 게임 화면의 표시명은 기획자가 확정한다. 제작 도면의 픽셀 좌표는 도면 대응 확인용으로만 제공한다.
- AI에 두 안전 구역의 경계, 그 사이 도로·보도의 일반 좀비 생성·이동 영역, 보스 전투 경계와 이동 가능 영역, 수취인 등장 위치를 제공한다.
- 플레이어 전투에 차량 진입·회차·주차 공간과 보행·사격 시야를 확인할 수 있는 테스트 구역을 제공한다.

## 완료 확인

모든 배송지 Actor가 코어 발급 ID 하나를 가지며, 누락·중복·미정의 ID가 레벨 검수와 서버 시작 검증에서 오류로 확인된다. 실제 위치·문·상호작용점이 코어 배달 정의의 목적지와 일치하고, 차량·AI·플레이어가 주요 동선에서 막히지 않아야 한다.

한 명과 네 명이 각각 우체국에서 나와 같은 지도에서 차량/총 상점에 들르고, 가까운 목적지까지 차로 이동해 배송한 뒤 우체국으로 돌아온다. 우체국에서 총 상점까지 걸을 때 두 건물 사이에서 일반 좀비와 마주칠 수 있고, 어느 건물 안으로 들어가도 좀비가 따라 들어오지 않는다. 총 상점 출입만으로는 저장되지 않고 야외에서 우체국 안전 구역으로 들어오면 저장 판정이 일어난다. 이 과정에 구역 전환 로딩이 없고, 배달 중인 다른 팀원이 우체국에 남아 있거나 보스 앞에 먼저 가 있어도 진행이 막히지 않는다. 차량 상실 후에도 우체국 근처에서 기본 권총으로 재시작할 수 있다. 거리별 실제 소요시간을 기록해 시간 기준 조정 자료를 낸다.
