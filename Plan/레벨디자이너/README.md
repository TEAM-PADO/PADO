# 레벨디자이너 작업 안내

먼저 [담당 기획서](02_레벨디자이너.md)를 읽는다. 1단계는 우체국·두 상점·좀비가 있는 도로·가까운 배달지 1곳을 한 지도에 연결하고 이동시간을 측정할 수 있게 만드는 것이다. 후속 산출물은 **오픈 지도·배달지 상세 배치도**다.

블록아웃 제작용: [도시 구조 블록아웃 PNG](도시_구조_블록아웃.png) · [중앙 거점 확대 PNG](중앙_거점_블록아웃.png) · [수정 가능한 블록아웃 SVG](도시_구조_블록아웃.svg).

블록아웃은 상세 지도와 같은 표시 좌표와 확대 범위를 사용한다. 회색 건물 덩어리, 중앙 시설의 외곽·출입구, 1층 실내 안전 영역 초안, B3 차단과 남쪽 우회를 구별했다. 중앙 확대 시트에서 우체국·총 상점 사이 야외 횡단과 차량 상점 진입을 확인할 수 있다.

우체국·총 상점·차량 상점이 중앙에 모이는 조건을 유지했다. 시장 앞 보도와 뒤편 하역 골목, 주택 현관·안뜰·공동 주차, 철도 물류 진입로, 학교 부지, 강변 범람원, 과수원 교회와 작업장을 구분해 사람이 살던 동선을 드러냈다. 도면 글자는 별도 한국어 문자 레이어로 정리했고, 일반 배달 9곳·보스 3곳은 동일 표시 좌표로 전체·상세·확대 시트에 반영했다.

PNG는 검토용 개념 배치도다. 실측 거리·도로 폭·현관 위치·실내 안전 경계는 블록아웃에서 확정한다. 수정에 필요한 배경·SVG·문자와 핀 좌표·출력 도구는 [도면 원본](도면_원본_v3/)에 모았다. 글자와 핀은 원본에서 바꾼 뒤 PNG를 다시 출력할 수 있다.
