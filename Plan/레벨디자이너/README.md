# 레벨디자이너 작업 안내

먼저 [담당 기획서](02_레벨디자이너.md)를 읽는다. 1단계는 우체국·두 상점·좀비가 있는 도로·가까운 배달지 1곳을 한 지도에 연결하고 이동시간을 측정할 수 있게 만드는 것이다. 후속 산출물은 **오픈 지도·배달지 상세 배치도**다.

공용 입력: [기본 규칙](../공용/00_기획핵심과_미결정.md) · [단계별 범위](../공용/01_개발순서.md) · [안전 구역과 저장 판정](../공용/07_배달_상태와_저장_규칙.md) · [목적지 ID와 거리](../공용/09_배달_콘텐츠_진행표.md) · [수취인·결말 공간](../공용/12_수취인_이야기_연출안.md) · [배치도 작성 요청](../공용/13_팀원별_문서_작성_요청.md).

[레벨 레퍼런스](레벨%20레퍼런스/)는 이 폴더에 둔다. 현재 레퍼런스 파일은 없다.
