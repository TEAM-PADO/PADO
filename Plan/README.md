# 기획 문서 안내

기획·PM 현황을 빠르게 확인하려면 [프로젝트 대시보드](Dashboard/index.html)를 브라우저에서 연다. [사용·갱신 안내](Dashboard/README.md)에 팀 변경을 받은 뒤 갱신하는 방법이 있다.

**팀 공용 기획 원본은 Plan 폴더에서 관리한다.** Docs에 있던 중복 기획서는 내용과 변경 이력을 비교해 [기획 핵심](공용/00_기획핵심과_미결정.md)으로 통합했다. 같은 기획을 두 폴더에서 따로 수정하지 않는다.

담당자는 **자기 폴더의 `README.md`와 기획서**, 그리고 [공용 문서](공용/README.md)를 기준으로 작업한다. 다른 담당 폴더의 문서를 읽어야만 자기 작업을 시작할 필요가 없도록 공통 규칙과 기획 입력은 공용에 모았다.

| 담당 | 시작 문서 |
|---|---|
| 레벨디자이너 | [레벨디자이너 폴더](레벨디자이너/README.md) |
| 네트워크 코어 | [네트워크 코어 폴더](네트워크_코어/README.md) |
| AI 프로그래머 | [AI 프로그래머 폴더](AI_프로그래머/README.md) |
| 플레이어 전투 | [플레이어 전투 폴더](플레이어_전투/README.md) |
| UI/클라이언트 시스템 | [UI/클라이언트 시스템 폴더](UI_클라이언트_시스템/README.md) |

공통 게임 규칙은 [기획 핵심](공용/00_기획핵심과_미결정.md)을 우선한다. 단계별 범위는 [개발 순서](공용/01_개발순서.md), 사건별 판정은 [배달 상태·저장 규칙](공용/07_배달_상태와_저장_규칙.md)을 확인한다. 충돌하거나 미정인 값은 [팀원별 작성 요청](공용/13_팀원별_문서_작성_요청.md)의 방식으로 기획자에게 제안한다.
